# WazirX

WazirX is an Indian cryptocurrency exchange (transitioning to Zettai following a 2024 restructuring) that provides REST and WebSocket APIs for automated spot trading, market data streaming, order management, account operations, and wallet functions across INR and crypto markets.

## APIs

- **REST API** — `https://api.wazirx.com` — Spot trading, orders, market data, account, wallet, sub-accounts
- **WebSocket API** — `wss://stream.wazirx.com/stream` — Real-time trades, tickers, klines, order book depth, private account streams
